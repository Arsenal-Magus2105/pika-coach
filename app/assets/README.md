# Pikafish NNUE

Run `../scripts/fetch_nnue.sh` from the repository root before building the
application. The script downloads the official network, verifies its SHA-256,
and writes `pikafish.nnue` in this directory.

The network is intentionally not committed because its license is separate
from the GPL-3.0 application source. See `../../THIRD_PARTY_NOTICES.md`.
